# 报表格式生成器

一个基于 Streamlit 的小工具：选一种报表 → 填几项基本信息 → 下载一个
**排版已完成、内容为空** 的 Excel 文件。之后只需往里填数据，不用再调格式。

支持上传你自己的空白 `.xlsx` 作为底板，也支持不上传直接新建。

## 内置报表

| 报表 | 特点 |
|---|---|
| 财务状况表 | 46 行会计科目已排好，各级合计自带 `=SUM()` 公式，行次自动编号 |
| 收支明细表 | 预留 N 行空行，末尾自动合计，结算方式带下拉选项 |
| 员工工资表 | 应发 / 代扣 / 实发分栏，底部自动汇总 |
| 库存盘点表 | 账面数与实盘数对照，盘点结果带下拉选项 |
| 项目进度表 | 阶段、状态、风险等级均为下拉选择 |

## 本地运行

```bash
pip install -r requirements.txt
streamlit run app.py
```

浏览器打开 http://localhost:8501 即可。

## 部署到 Streamlit 官方云

1. 把本仓库推到 GitHub（**公开仓库**，官方云免费版的要求）。
2. 打开 https://share.streamlit.io ，用 GitHub 账号登录。
3. 点 **New app**，选择仓库和分支，Main file path 填 `app.py`，Deploy。
4. 等一两分钟构建完成，会得到一个 `https://xxx.streamlit.app` 的公网地址。

### 设置访问密码（强烈建议）

代码里**不包含**任何密码。部署后到云端后台：
应用右上角三个点 → **Settings** → **Secrets**，填入：

```toml
access_password = "你的密码"
```

保存后应用自动重启，之后打开网页需先输密码。
未配置密码时页面会显示一条提醒，并且不加限制（方便本地开发）。

## 代码结构

| 文件 | 作用 |
|---|---|
| `app.py` | Streamlit 网页界面与访问密码闸门 |
| `excel_engine.py` | 排版引擎：把报表定义渲染成带格式的空白工作簿 |
| `report_specs.py` | 报表定义（纯数据）。**新增报表只改这个文件** |

## 新增一种报表

打开 `report_specs.py`，照着任意一个 `ReportSpec` 复制一份，
改改列（`Column`）和行（`RowSpec`），再加进文件末尾的 `REPORTS` 元组。
刷新网页即可看到新选项，不需要改动引擎和界面。
